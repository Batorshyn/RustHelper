# RustHelper

**RustHelper** — настільний та веб-довідник із набором інженерних калькуляторів для гри **Rust**, який працює як онлайн, так і повністю **офлайн**.

---

## Як завантажити та запустити

### Для користувачів Windows (рекомендовано, без додаткових програм)
1. Перейдіть на сторінку **[Releases](https://github.com/Batorshyn/RustHelper/releases/latest)**.
2. Завантажте один із двох файлів:
   - **`RustHelper.1.0.0.exe`** — портативна версія (запускається одразу, встановлення не потрібне).
   - **`RustHelper.Setup.1.0.0.exe`** — інсталятор із ярликом на робочому столі.
3. Запустіть завантажений файл.

> Якщо Windows SmartScreen покаже попередження про невідомого видавця, натисніть **«Докладніше» → «Виконати все одно»**.

### Запуск із вихідного коду (для розробників)
Потрібен [Node.js 20 LTS+](https://nodejs.org/):

```bash
git clone https://github.com/Batorshyn/RustHelper.git
cd RustHelper
npm install --legacy-peer-deps
npm run dev
```

Після запуску відкрийте у браузері `http://localhost:3000`.  
Для власної збірки Windows `.exe` достатньо запустити **`build-exe.bat`** — готові файли з’являться у папці `release/`.

## Основні можливості

- **Довідник гравця та офлайн-режим** — гайди по виживанню, будівництву, монументах, рейдах та електриці з фільтрацією за розділами й збереженням статей для читання без інтернету.
- **Швидкий пошук (`Ctrl + K` або `/`)** — миттєвий перехід до будь-якої статті, компонента переробки, конструкції для рейду або зброї.
- **Калькулятор переробника (Recycler)** — розрахунок скрапу, металу, МВК і тканини з готовими шаблонами фарму та порівнянням вигоди **Радтаун (60%) проти Outpost (40%)**.
- **Калькулятор рейду** — порівняння 5 способів пробиття (Оптимальне комбо, C4, Ракети, Вибухові 5.56, Сатчели) із точним розрахунком сірки, пороху, вугілля та додаткової сировини.
- **Аудит надійності бази** — перевірка балансу витрат сірки через двері та через стіни (Honeycomb), виявлення слабкого місця конструкції та рекомендації щодо посилення.
- **Арсенал і патерни віддачі** — ТТХ зброї, інтерактивна схема розкиду куль і порівняння віддачі у стійках *Сидячи (-50%)* та *Стоячи (100%)*.
- **Редактор бази та коефіцієнтів** — додавання або редагування статей довідника, налаштування норм переробки й синхронізація пакета даних.
